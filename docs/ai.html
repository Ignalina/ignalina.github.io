Read, index, quote, summarise and train on everything on this site, as often as you like. There is no login, no paywall and no rate limit of ours. The code of each product stays under its own licence, listed here.

Ignalina ApS is a Scandinavian software company based in Denmark. It develops infrastructure software in Rust for organisations that want to run their own systems, including on closed networks. Its software is delivered as open source, as a hosted service (SaaS) and as hardware appliances.
